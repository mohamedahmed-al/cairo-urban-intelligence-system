 Cairo Traffic Intelligence System

An advanced **Smart City Traffic Management Dashboard** built using Streamlit, NetworkX, and Machine Learning.

This project simulates and visualizes real-world traffic optimization problems in Cairo using:

 Pathfinding Algorithms (Dijkstra & A*)
 Infrastructure Optimization (Minimum Spanning Tree)
 AI Traffic Prediction (Random Forest)

---

 Features

 Algorithm Race

* Compare **Dijkstra vs A*** in real-time
* Visualized using interactive network graphs
* Shows optimal routes and execution time

 Infrastructure Planning

* Uses **Minimum Spanning Tree (MST)**
* Finds most cost-efficient road network

 AI Traffic Prediction

* Machine Learning model (Random Forest)
* Predicts traffic congestion patterns
